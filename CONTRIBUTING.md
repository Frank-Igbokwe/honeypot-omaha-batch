# Contributing to Project Honeypot-Omaha

First off, thank you for taking the time to contribute! Open-source security tools thrive on community collaboration, real-world testing, and peer feedback.

## How Can I Contribute?

### 1. Reporting Bugs & Issues
If you encounter a bug, parsing error, or unexpected behavior with `batch.py` or the GUI:
* Open an issue in the **GitHub Issues** tab.
* Provide a clear description of the problem, your environment (macOS, Linux, WSL), and steps to reproduce it (while ensuring no sensitive production logs or internal IPs are exposed).

### 2. Suggesting Enhancements
Have an idea for a new log parser, feature, or optimization? 
* Open an issue labeled **"Feature Request"** to discuss the change before writing code.

### 3. Pull Requests
* Fork the repository and create your feature branch from `main`.
* Ensure your code follows clean Python formatting standards (PEP 8).
* Test your changes thoroughly against sample log datasets.
* Submit a pull request with a clear description of what your changes solve.

Thank you for helping improve open-source threat intelligence tooling!
