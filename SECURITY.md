# Security Policy

## Supported Versions

Currently, the active `main` branch of Project Honeypot-Omaha is supported with security updates and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| Main (Latest) | :white_check_mark: |
| Older Releases | :x:              |

## Reporting a Vulnerability

If you discover a security vulnerability within `batch.py` or the GUI components, please report it responsibly. 

* **Do not** disclose security vulnerabilities publicly through open GitHub issues, pull requests, or public discussions.
* Instead, please report them privately. You can reach out directly via professional channels or repository contact methods.
* You can expect an initial acknowledgment of your report within a few days, followed by updates as the issue is reviewed and addressed.
