# Getting Support

If you need help installing, configuring, or running Project Honeypot-Omaha, here are the best places to find assistance:

* **GitHub Issues:** For bug reports, installation errors, or technical questions about the codebase, open an issue on the [GitHub Repository](https://github.com/Frank-Igbokwe/honeypot-omaha-batch/issues).
* **Documentation:** Review the `README.md` for complete installation steps and CLI usage examples.
* **Community Discussions:** Feel free to reach out via professional networks or share feedback on how the pipeline performs in your environment.
